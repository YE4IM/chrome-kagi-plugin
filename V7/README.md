# 主页新标签页

轻量的 Manifest V3 Chrome 扩展：打开新标签页后跳转到指定主页。默认主页为 `https://kagi.com/`，仅使用 `storage` 权限，无后台常驻脚本。

## 使用与更新

1. 打开 Chrome 的 `chrome://extensions/`。
2. 首次安装时开启开发者模式，点击“加载已解压的扩展程序”，选择本目录。更新已有安装时，在此扩展卡片上点击重新加载。
3. 打开扩展的选项页，填写主页地址，点击“保存设置”。预设与“恢复默认地址”都只修改草稿，保存后才生效。

已有版本保存在本机的 `homepage` 会继续使用，不会自动启用同步。自定义地址可以直接编辑，支持域名、中文域名、IPv4、IPv6 和内网主机名。省略协议时使用 HTTPS；本地 HTTP 服务需明确填写 `http://`。

## 可选同步

“跨设备同步主页”默认关闭。勾选并保存后，会将当前地址写入 Chrome 同步存储；其他设备也需要开启此选项，并在 Chrome 中使用同一账号开启扩展程序同步。启用并保存会应用当前输入框中的地址，覆盖同步存储里的旧地址。

关闭同步只影响本机，不会清除其他设备的同步地址。关闭时，当前显示的地址会保留在本机。同步读取失败时暂时使用本机保存的地址；保存失败会显示错误并保留草稿供重试。Chrome 关闭同步或离线时，`storage.sync` 仍可在本机保存，扩展显示保存成功并不代表其他设备已经收到更新。

## 隐私与恢复

预设图标随扩展打包，自定义图标在本机生成。编辑地址时不会请求目标网站或任何第三方图标服务。只有启用同步并保存后，主页设置才会交由 Chrome 同步。

设置页支持键盘操作、读屏状态反馈、减少动画偏好及深浅色模式。长网址自动换行显示。读取设置失败时可重新读取；新标签页读取失败或已保存地址无效时使用默认主页。页面等待超过三秒或跳转同步抛出异常时，会显示手动打开、设置和重试入口。导航离开扩展后出现的浏览器网络错误页由 Chrome 管理，扩展无法在该错误页中插入恢复入口。

## 验证

安装 Node.js 后运行，无需安装依赖：

```sh
node --test tests/*.test.cjs
```

测试覆盖 URL 规范化、旧设置兼容、异常数据、存储错误、同步开关与回退、新标签页跳转及恢复入口。`tests/mock-chrome.js` 仅用于在本地预览页面时模拟 Chrome 存储 API，不会被扩展页面引用。

浏览器检查使用了模拟的 Chrome 存储 API，验证了保存、错误重试、草稿保留、远端更新、深浅色和窄窗口布局、图标资源及实际页面跳转。真实的跨设备同步仍需在使用同一账号的 Chrome 设备上确认。
